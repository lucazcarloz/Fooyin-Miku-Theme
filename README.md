# Fooyin Hatsune Miku Theme
Tema personalizado para o Fooyin baseado na Hatsune Miku.

Fiz esse tema através da ferramente de edição nativa do software. Apenas uma customização simples com algumas artes ASCII que achei bonitas. Completamente editável a gosto do usuário.

<img width="1920" height="1080" alt="image" src="https://github.com/lucazcarloz/Fooyin-Miku-Theme/blob/main/image.png?raw=true" />

A imagem de fundo playlist pode ser escolhida manualmente nas configurações do Fooyin, conforme imagem abaixo:

<img width="1897" height="1064" alt="image" src="https://github.com/user-attachments/assets/91b3be59-8b14-4034-bbb1-0f2243ebebb1" />

Siga a janela, conforme as opções indicadas e selecione a imagem que desejar para o tema de fundo da lista de reprodução. Imagem utilizada nesse exemplo segue nos arquivos do repositório.
